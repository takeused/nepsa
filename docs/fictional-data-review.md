검토일: 2026-09-05. 입력: `docs/example-portfolio.json`. 입력 데이터와 앱의 채점 규칙은 변경하지 않았다.

## 결론

가상자료만으로도 현 단계의 개발과 구현 검증을 계속할 수 있다. 실제 과제 확보는 개발의 선행 조건이 아니다. 다만 가상자료의 일관된 계산 결과가 KEIT 공식 산식이나 현실 과제의 우선순위 타당성을 입증하지는 않는다.

## 자료의 구분

- **원문 예시 10개:** AAA~JJJ 종합점수를 직접 입력한 자료. 원문과 등급·순위를 대조할 수 있지만 지표별 원점수가 없어 환산식을 검증할 수 없다.
- **Claude 가상 과제 14개:** 기업주관형 11개, 원천기술형 3개. 12개 지표를 모두 채운 시연 자료이며, 각 근거에 가상 수치임을 밝혔다. IP는 13개가 자동 채점, 1개(뇌-기계 인터페이스)가 수동 3점이다.

## 대표 계산: 특수목적 반도체 테스트 소켓

기대성과 지표는 기술 수월성 4, 응용가능성 2, IP 부상도 3, 시장 5, 영업이익률 5, 파급효과 3점이다. 각각 11.25 + 2.50 + 7.50 + 25.00 + 15.00 + 10.00 = **71.25점**.

위험은 기술격차 2, 인프라 1, IP 장벽 1, 경쟁강도 1, 사업화 자원 2, 수명주기 2점이다. 5.00 + 0 + 0 + 0 + 2.50 + 3.75 = **11.25점**. 따라서 A2이며 기업주관형 2위다. 과거 기록에 이 과제가 S라고 되어 있더라도 현재 파일의 수치로는 A2가 맞다.

## 가정에 대한 민감도

**환산식만 구 ÷5 방식으로 바꾼 실험:** 동일한 지표 점수에 대해 새 종합점수 = 20 + 0.8 × 현재 종합점수다. 세부 영역이 5개 과제에서 바뀐다.

| 과제 | 현재 (n−1)÷4 | 구 ÷5 |
|---|---|---|
| 차량용 라이다 수신광학계 국산화 | B2 | B1 |
| 산업용 협동로봇 고정밀 그리퍼 | B3 | B2 |
| CCUS용 저재생에너지 아민 흡수제 | A1 | B1 |
| 특수목적 반도체 테스트 소켓 | A2 | A1 |
| 침습형 뇌-기계 인터페이스 신호처리 | B3 | B2 |

대등급 문자가 바뀌는 과제는 CCUS(A→B) 1개다. 기업주관형 5개 과제의 순위도 달라진다. 특히 CCUS는 현재 1위에서 구 방식 5위, 테스트 소켓은 2위에서 1위로 바뀐다. 원천기술형의 순위는 그대로다. 이 차이는 환산식에 따른 민감도이며 어느 식이 공식적으로 옳은지의 판정이 아니다.

**IP 평균의 사사오입을 생략한 실험:** 환산식은 현재 방식으로 유지했다. 14개 중 자동 채점 10개의 기대성과가 변하며, 변동의 절댓값은 최대 1.875점이다. 이 자료에서는 영역과 순위 변화가 없다. 경계에 더 가까운 다른 과제에서도 안전하다는 뜻은 아니다.

## 검증 범위의 한계

- 14개는 A1·A2·B1·B2·B3·C2·C3의 **7개 영역**만 포함한다. S·B4·C1·D1·D2는 없다.
- 원천기술 3개 모두 도전적 R&D 영역 안이다. 영역 밖, 누락 입력, 동률도 이 파일로는 점검하지 못한다. 이 경우는 기존 별도 단위 테스트에서 다룬다.
- 정성 분포 60% 초과 경고는 기업주관 5개 지표, 원천기술 4개 지표에서 발생한다. 의도적으로 경고 사례를 넣은 시연 자료이므로 평가가 완료된 실무 포트폴리오로 해석하면 안 된다.
- 실세계 기술명을 사용하지만 시장·특허·기술수준 숫자는 조사값이 아니다. 모델의 경제적 타당성 검증에는 사용할 수 없다.

## 권장 진행 방향

현재 자료를 회귀 기준으로 계속 사용한다. 추가 검증은 실제 과제를 기다리기보다 S·D 영역, 원천기술 하한 60/40 전후, 등급 경계, 동률, 누락 입력을 의도적으로 만든 합성 시나리오로 수행할 수 있다. 상당수는 이미 단위 테스트로 검증한다. 향후 필요할 때 해당 시나리오를 웹앱에서 직접 불러볼 수 있는 별도 시연 묶음으로 확장하면 된다.

가상자료는 앱 하단 **백업 불러오기**에서 `docs/example-portfolio.json`을 선택해 열 수 있다. 상단 **원문 예시 불러오기**는 별도 AAA~JJJ 자료다. 이번 검토에서는 브라우저에 저장된 사용자 작업을 교체하지 않았다.
