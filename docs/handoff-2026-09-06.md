- `app/globals.css`: 라이트·다크·반응형·인쇄 스타일.

## 데이터 보관 주의

- 실제 사용자 작업은 브라우저 localStorage에 있다. 코드 저장소에는 포함되지 않는다. 검증 목적으로 기존 작업을 교체하지 말 것.
- 원본 과제: `nepsa-workbench-v1`. 과거 원본 복구 키: `nepsa-workbench-v1-original`.
- 평가 이력: `nepsa-evaluation-history-v1`, 최대 20회/5MB. 일반 과제 백업과 별도 JSON을 사용한다. 저장 전 외부 변경을 검사한다.
- 시나리오: React 상태에서 유지되며 탭 이동은 보존, 새로고침은 초기화된다. 전용 JSON으로 기준 과제·편집 중인 값·최대 3개 시나리오를 함께 백업·복원한다. 원본 과제에는 반영하지 않는다.
- 기준 과제가 수정·삭제되면 시나리오 순위 비교를 중지한다. 다른 과제만 변경된 경우에는 현재 포트폴리오 기준 순위로 비교한다.
- 출처·기준연도·가정·확신도는 기존 notes 맵의 `지표ID:source/year/assumption/confidence`에 저장한다. 과제 백업과 상세 CSV에 포함된다.
- 임시 검산 파일 `tmp/`는 Git에서 제외한다. 재현 가능한 테스트와 결과 보고서는 추적한다.

## 모델의 한계

- `(가중평균−1)÷4×100`과 IP 평균 정수 반올림은 구현 가정이다. 원문 공식으로 확정했다고 설명하지 않는다.
- ÷5 방식도 S 영역에 도달할 수 있다. 이전 기록의 불가능 주장은 정정했다.
- 원천기술형은 성과≥60, 위험≥40일 때만 등급·순위가 있다. 영역 밖을 탈락 등급으로 바꾸지 않는다.
- 이력의 모델 버전이 현재와 다르면 안내 후 현재 모델로 재계산한다. 과거 모델 실행 엔진을 보존하지 않는다.
- 가상자료 검증은 계산 일관성을 확인하며 현실 예측력이나 공식 기준과의 일치를 입증하지 않는다.
