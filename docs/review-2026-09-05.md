# Claude 작업 인수 검토와 보완

검토 기준: 기존 커밋 `7df046f`, 제공된 KEIT 2013 문서와 작업 기록, 현재 코드. 기존 작업 트리는 검토 시작 시 깨끗했다.

## 인수 시점 상태

12개 지표 평가, IP 자동 채점, 등급 매트릭스, 유형별 순위, 근거 기록, 기기 내 저장, CSV/JSON, 라이트·다크, 인쇄 스타일이 구현되어 있었다. 기존 테스트 57개와 린트는 통과했다. 고정 환산식과 정렬, 기존 디자인을 유지했다.

## 보완한 문제

1. **저장본이 다시 열리지 않는 입력 경로:** 이름을 비운 순간이나 101점 같은 입력도 자동 저장되지만 가져오기 검증에서 거부되었다. 저장 전에 같은 검증을 적용하고, 오류 상태에서는 마지막 정상 저장본을 유지한다. 오류 수정 후 자동 저장을 재개하며 오류 상태의 내보내기도 막는다.
2. **IP 부분 입력이 수동 점수로 대체됨:** 자동 입력을 시작한 뒤 값 하나를 지우면 과거 수동 점수가 다시 적용되었다. 네 값 중 하나라도 입력했으면 자동 모드로 처리하며, 미완료·범위 오류는 채점하지 않는다. 네 값을 모두 비워야 수동 점수를 사용한다.
3. **정량 범위 검증:** 점유율 0~100%, 증가율 −100% 이상, 시장 구분 0/1, 비음수 비용·기간 등을 검증한다. 영업손실률은 음수를 허용한다. 잘못된 시장 구분을 국내시장으로 해석하지 않는다.
4. **구버전 재계산이 드러나지 않음:** 백업에 모델 식별자를 기록한다. 모델이 다르거나 기록이 없는 백업을 불러올 때 현재 기준으로 재계산됨을 알린다. 기존 자동 저장 데이터를 이전할 때 원본을 별도 보존하며 다운로드 기능을 제공한다. 읽기 실패 시에도 원본을 덮어쓰지 않는다.
5. **출처 확실성의 과장:** ÷5 환산으로도 기대성과 100·위험 20은 S등급이다. 고정 환산식은 공식 확인이 아닌 구현 가정임을 정정했다. CODIL 본문의 ‘높은 수준’ 표현만으로 IP 평균 사사오입이 확정되는 것은 아니므로 반올림·구간 경계도 가정으로 명시했다.
6. **산출 내역과 인쇄:** 각 지표의 축 점수 기여분을 표시한다. 인쇄에서 숨겨졌던 수동 IP 점수를 표시하고, 긴 과제명과 직접 입력 근거를 정적인 텍스트로 남긴다.
7. **예시 추가 한도:** 원문 예시 불러오기에도 1,000개 제한을 적용했다.

## 검증

- 원문 10개 과제의 등급·순위 회귀를 유지했다.
- 기존 14개 가상 과제의 입력값·점수가 백업·복원 후 유지되는지 검증한다.
- 저장 검증, 모델 변경 안내, IP 부분 입력과 범위 오류, 구 환산식의 S영역 도달 사례를 추가 검증한다.
- 타입 검사, 린트, 프로덕션 빌드 및 로컬 HTTP 응답을 확인했다.
- 이번 검토에서 브라우저 클릭·시각·실제 인쇄 테스트는 수행하지 않았다. 인쇄 변경은 CSS와 렌더 구조 검토 범위이다.

## 다음 작업의 우선순위

현재 단계에서 로그인·서버 저장·협업을 먼저 추가할 필요는 없다. 실사용 과제 3~5개와 평가자가 작성한 원점수·최종 결과를 대조해 환산식, IP 반올림, 경계값을 먼저 검증하는 것이 중요하다. 여러 평가자가 실제로 참여하게 되면 평가자별 입력과 집계 방식, 평가차이 표시를 다음 범위로 삼을 수 있다.

기존 화면은 기기 내 저장 방식이며, 이번 검토는 로컬 코드 보완이다. 배포·GitHub 푸시는 수행하지 않았다.
