# 브라우저 조작 검증 — 2026-09-06

대상: `vinext dev` (localhost:3000), 데이터는 `docs/example-portfolio.json`(가상 과제 14개)을 앱의 **백업 불러오기**로 적재.

## 검증 방식과 한계

브라우저 창이 배경에 있어 `document.visibilityState`가 계속 `hidden`이었다. 그 상태에서는
픽셀 클릭·키 입력이 React 핸들러에 도달하지 않았고 Base UI 팝업(Select)이 열리지 않았다.
그래서 버튼은 `element.click()`, 입력은 네이티브 setter + `input` 이벤트로 조작했다.
앱의 실제 핸들러·상태·localStorage 경로는 모두 실행되지만 **사람이 마우스로 누른 것과 같지는 않다.**
아래 "미검증"은 이 제약 때문에 남은 항목이다.

## 미검증 (창을 앞으로 가져온 뒤 재확인 필요)

- 정성지표 6개의 점수 드롭다운, 대상시장·평가 방식·과제 유형 선택 — 배경 창에서는 팝업이 열리지 않아 조작하지 못했다.
- 실제 화면 렌더링·모바일 폭(패널이 375px 뷰포트를 적용하지 않고 837px로 고정됨).
- 실제 인쇄 미리보기와 PDF 출력, Excel에서의 CSV 열기.
