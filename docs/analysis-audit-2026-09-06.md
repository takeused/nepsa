# 분석 기능 추가 및 로직 점검 — 2026-09-06

## 추가한 기능

- 분석·이력·비교 탭: 항목별 축 기여점수와 현재 영역의 실제 좌표 범위.
- 시나리오: 동일 과제 유형의 복사본을 편집하고 전후 매트릭스·전체 순위를 비교. 최대 3개를 이름으로 보관한다. 원본 포트폴리오에는 반영하지 않는다.
- 시나리오 전용 JSON: 기준 과제, 편집 중인 값, 보관한 시나리오를 함께 백업·복원한다. 일반 과제 백업과 형식을 구별한다. 탭 이동 시 유지되지만 새로고침 전에는 백업이 필요하다.
- 평가 이력: 전체 포트폴리오 스냅숏 최대 20회, 별도 백업·병합·삭제. 이력 이름에 평가 시점과 변경 이유를 기록한다.
- 이력 비교: 추가·삭제·유형 변경, 직접 입력 점수, 지표·정량 입력·근거의 전후 값. 유형별 순위는 한 번씩 계산하고 고유번호로 연결한다.
- 최대 4개 과제의 지표·근거 비교, 지표별 출처·기준연도·가정·확신도 기록.
- Excel용 상세 CSV, 기존 인쇄/PDF 출력 버튼. XLSX 생성 기능은 아니다.

## 점검 중 보완

1. 이력 비교는 배열 위치가 아닌 과제 고유번호로 대조한다. 테스트도 순위 때문에 바뀐 배열 순서에 의존하지 않게 수정했다.
2. 시나리오 3개 초과 시 오래된 항목을 조용히 삭제하지 않고 보관을 거절한다. 같은 이름은 갱신한다.
3. 원본 수정·삭제·유형 변경 시 오래된 기준으로 순위를 비교하지 않는다. 백업 검증이 보충하는 sample 플래그 차이가 오탐을 만들지 않도록 기준 과제를 정규화한다.
4. 시나리오 백업에는 기준 과제와 현재 편집값을 포함한다. 다른 유형 혼합, 중복 이름, 잘못된 점수, 5MB 초과를 거절한다.
5. 이력은 외부 탭의 저장값과 다르면 쓰기를 중단한다. 저장 공간 오류가 나면 성공 상태로 바꾸지 않는다.
6. 삭제된 과제를 비교 선택 한도에서 제외한다.
7. 지표 범위 밖 점수는 기여점수로 표시하지 않는다. 미완료·영역 밖 상태를 구별한다.
8. CSV의 수식 시작 문자와 따옴표를 이스케이프한다. 출처 등 새 근거 필드는 기존 과제 JSON으로 보존된다.

## 검증과 한계

- `npm test`: 125개 통과. 기존 가상자료 14개 대조, 기술격차 소수점 경계, 양 유형 전체 영역·단조성 검사 포함.
- `npm run lint`, `tsc --noEmit`, `npm run build` 통과.
- 브라우저 조작·시각 검수, 실제 인쇄 및 Excel 실행은 수행하지 않았다.
- 이력과 시나리오는 일반 과제 JSON과 별도 백업이다. 로컬 저장 공간을 공유하므로 브라우저 용량에 따라 20회보다 먼저 저장이 실패할 수 있다. 저장 실패 시 기존 값은 보존한다.
- 이력 모델이 현재와 다르면 경고하고 현재 기준으로 재계산한다. 과거 모델의 실행 엔진을 보존하는 기능은 아니다.
- 기존 평가 가정(100점 환산, IP 정수 반올림 등)을 공식 산식으로 확정한 것은 아니다. 실제 과제 자료의 실증 검증도 수행하지 않았다.
